## 📌 头条

### 苹果秋季发布会：iPhone 18 Pro 与折叠屏 iPhone Duo

苹果在昨天的秋季发布会上推出了 iPhone 18 Pro 系列，主打相机升级并新增酒红配色，同时首次带来折叠屏机型 iPhone Duo，以及新一代 Apple Watch。这是今年智能手机涨价潮里最受关注的一场，多家媒体也指出「换机需求被压制、功能升级越来越不显性」是行业普遍焦虑。值得留意的是，部分软件功能不随硬件首发：Siri 的 AI 能力下月才拓展更多语言，Apple Watch 的新功能要等到年底。对做产品的人来说，折叠屏成为主流大厂标配这件事，比单纯的参数升级更值得跟。

→ [TechCrunch](https://techcrunch.com/2026/09/09/apple-launches-iphone-18-pro-with-upgraded-camera) / [发布会回顾](https://sspai.com) / [功能延后](https://www.ithome.com)

### Shopify 收购 Tailwind Labs

Tailwind CSS 作者 Adam Wathan 宣布团队加入 Shopify。Tailwind 目前每周被安装超过 1.1 亿次，ChatGPT、X、Cloudflare、Reddit 都在用它。官方明确承诺 Tailwind CSS 及其它开源项目保持 MIT 许可、由原团队继续维护，变化在商业侧——不再扩张围绕 Tailwind 的付费业务，Tailwind Plus 等产品停止新用户注册、只保留现有客户。对每天用 Tailwind 的前端来说框架本身不受影响，但一个独立开源商业项目被平台公司收编，是这两年前端基础设施「找长期归宿」趋势的又一例。

→ [官方公告](https://tailwindcss.com/blog/tailwind-is-joining-shopify) / [HN 讨论](https://news.ycombinator.com/item?id=49626190)

## ⚡ 快讯

- **Kubernetes v1.37**：引入五个标准化的节点生命周期状态（DrainInProgress / Drained / MaintenancePlanned 等），给「节点正在排空/维护/优雅关机」一个 K8s 官方统一表达。注意这是 Alpha、feature gate 默认关闭，本版本核心组件还不消费这些状态，先解决的是运维可观测性 → [官方博客](https://kubernetes.io/blog/2026/09/09/kubernetes-v1-37-node-lifecycle-conditions)
- **Cloudflare Workers**：重写了 workerd 的模块注册表，Node.js 兼容默认开启、单包上限提到 64 MiB，支持 import.meta.url/resolve() 等。开启 new_module_registry 兼容标志即可用，让更大的 Node.js 应用能直接跑在 Workers 上 → [Cloudflare 博客](https://blog.cloudflare.com/workers-module-registry-nodejs)
- **pnpm 12**：包管理器核心用 Rust 重写，在保留 pnpm 11 工作流的前提下提升安装速度。具体提速幅度以官方基准为准 → [InfoQ](https://www.infoq.cn/article/h4M6YGm3G7Zph5QEIV5R)
- **一篇「Go 重写后端省 94% AWS 账单」**：作者称 72 小时把后端重写成 Go，AWS 账单降了 94%，HN 上引发讨论（61 分）。是个人经验帖、样本单一，当作省钱思路参考而非普适结论 → [原文](https://www.bajura.online/2026/09/i-rewrote-my-backend-in-go-in-72-hours.html) / [HN](https://news.ycombinator.com/item?id=49611641)
- **Suno**：发布首个「与唱片业合作」制作的 AI 音乐模型，是 AI 音乐版权争议后行业转向合作模式的信号 → [The Verge](https://www.theverge.com)
- **Automattic**：WordPress 母公司 Automattic 的 CEO Matt Mullenweg 被董事会安排休假（placed on leave），在 WP Engine 纠纷持续背景下值得关注后续 → [The Verge](https://www.theverge.com)
