### LangChain 给多 Agent 加了「fork 上下文」模式

LangChain 在 deepagents 最新版里引入了 context modes，给 subagent 两种选择：isolated（默认，全新空上下文，只拿到任务描述）和 fork（继承 supervisor 的完整对话历史）。核心痛点很实在——isolated 模式下 subagent 会把 supervisor 已经做过的 file read、上下文收集重跑一遍，纯浪费。fork 模式把 supervisor 当前状态整个传下去，靠 prompt caching 省掉重复工作，更快也更便宜。选型建议清晰：worker（接着 supervisor 的调查继续干活）用 fork，verifier（独立评审已完成的工作）用 isolated。这正好对上你手上的多 Agent 编排——subagent 该不该带 supervisor 上下文，现在有了明确的按用途区分的答案，而不是一刀切全隔离。

→ [原文](https://www.langchain.com/blog/organizing-context-in-a-multi-agent-harness)

### Perplexity 本地 Agent 转投阿里 Qwen3.8

据 Siliconangle 报道，Perplexity 推出本地 Agent 产品 Portable Computer，底座换成了阿里开源的 Qwen3.8-27B，跑在英伟达 DGX Spark 硬件上，做文件处理、数据分析、编程等本地任务。值得注意的是这家一向用 Claude/GPT 的明星公司，Agent 布局从云端走向本地、模型从闭源转向开源 Qwen。报道称 Qwen3.8-27B 因智能密度被业界称为「本地 Opus4.6」。不过这些性能定位来自报道转述，没有官方 benchmark 数字，先当行业动向看。对本地部署 Agent 感兴趣的话，DGX Spark + 27B 量级模型这条路径值得留意。

→ [原文（雷峰网）](https://www.leiphone.com/category/industrynews/1fUYK0dGQLzXssbl.html)
